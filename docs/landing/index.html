The signature

An observable pipeline, not a churn-and-pray import.

Every document moves through explicit states, and the state is written to disk after each one. A crash resumes where it stopped. A failure is visible — never a silent drop.

discovered
a connector yields a source doc
extracted
text pulled (Tika, confined)
gated
cheap model filters junk
chunked
token-budgeted, with overlap
embedded
bge-m3, dim asserted
stored
idempotent upsert to Qdrant
skipped
the gate rejected it — on purpose, and logged with a reason
error
something failed — kept visible with its message, never discarded
Why it's different

The pipeline is the product.

The chatbot is a commodity. These are the things a black box won't give you — and the reasons your retrieval quality actually holds up.

observable

Know what happened to every file

An explicit state machine and a status view. No more "some PDFs just aren't in the answers and I can't tell why."

resource-aware

Built for one GPU, not a cluster

Stage-batched execution keeps the embedding model resident instead of thrashing VRAM on every document.

gated

Don't embed junk

An optional cheap-model relevance gate filters documents before the expensive embed step. Opt-in, per run.

idempotent

Re-run anytime, zero duplicates

Every chunk has a stable id. Re-ingesting updates in place — safe to run on a schedule.

correct

The dimension bug can't happen

Embedding dimension is asserted against the collection before any write. No more 1024-dim query against a 768-dim store.

private

Nothing leaves your network

Your Ollama, your Qdrant, your disk. An MCP server lets Claude Code retrieve from your store — still all local.

Quick start

Running in three commands.

Bring your own Ollama with bge-m3 pulled. ragkit brings the pipeline, Qdrant, and Tika.

# clone, configure, bring up Qdrant + Tika
$ git clone …/rag-starter-kit && cd rag-starter-kit
$ cp ragkit.example.yaml ragkit.yaml && docker compose up -d
$ pip install -e .
# point it at your documents, then ask
$ ragkit ingest /path/to/your/pdfs --collection mydocs
$ ragkit search "what's our renewal clause?" --collection mydocs --rerank
